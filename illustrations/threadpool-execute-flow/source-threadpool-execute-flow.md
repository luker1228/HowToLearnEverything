```text
提交一个任务（execute）
        │
        ▼
当前线程数 < corePoolSize ?
        │ 是
        ▼
   创建核心线程，直接跑这个任务
        │
        │ 否
        ▼
   队列没满 ?
        │ 是
        ▼
   任务塞进队列排队
        │
        │ 否（队列满了）
        ▼
   当前线程数 < maximumPoolSize ?
        │ 是
        ▼
   创建非核心线程，直接跑这个任务
        │
        │ 否（线程也到上限了）
        ▼
   执行拒绝策略
```
