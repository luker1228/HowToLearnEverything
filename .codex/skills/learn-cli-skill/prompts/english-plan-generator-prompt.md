# 英语学习计划生成提示词

```text
请基于现有的英语教练 `system prompt`，生成一份具体的英语学习计划。

这份计划不能停留在泛泛建议层面，必须拆成一个可执行的 12 周结构，并且后续可以被一个基于 CLI 的状态跟踪系统固化。

输出要求：
1. 定义整个 12 周的总目标。
2. 定义每一周的重点。
3. 定义每天 1 小时的学习节奏。
4. 把计划拆成模块，例如：口语、听力、阅读、写作、工作英语、复盘。
5. 把每个模块继续拆成足够小、可以成为独立跟踪项的具体学习点。
6. 明确区分：
   - 由用户自己提供的内容或材料
   - 应该进入跟踪系统的学习点
7. 对每个学习点，都要具体到足以支持：
   - 解释
   - 练习
   - 自测
   - 后续复习
8. 整个计划必须实用、现实，并且适合连续执行 12 周。
9. 不要假设系统会自动生成听力材料；如果听力训练依赖外部素材，要明确标记为“用户提供输入”。
10. 计划要容易映射成：
   - 一个 goal 文件夹
   - 多个 point Markdown 文件
   - 由 CLI 跟踪的学习和复习状态

最终计划至少要包含：
- 目标摘要
- 12 周时间安排
- 模块拆分
- 学习点列表
- 每日学习闭环
- 每周复习闭环
- 哪些部分属于内容设计，哪些部分只属于状态跟踪的说明
```
