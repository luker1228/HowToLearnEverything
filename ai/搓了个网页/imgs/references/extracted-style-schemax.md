# SchemaX Design System — extracted style for illustration

## Visual direction
- RetroUI / Neo-brutalism (north star: neubrutalism.com)
- Dual layer: **Structure** (3px black frame, zero-blur hard shadow, radius 0) + **Clash** (sticker-stack color clashing)
- No soft gradients, no glassmorphism, no diffused shadows
- Warm paper field as continuous canvas

## Structure rules
- Border: 2–3px solid black
- Radius: 0 (default), tiny 2px only for controls
- Shadow: pure black hard offset, zero blur — e.g. `3px 3px 0 #000`, `5px 5px 0 #000`, `8px 8px 0 #000`
- Square line caps; geometric icons (rect, line, star)

## Clash sticker energy
Yellow + coral + sky + soft green + orange as side-by-side sticker blocks; high contrast on paper; display-style bold titles.

## Typography feel
- Display: Bricolage Grotesque (bold, slightly condensed, editorial)
- Body/UI: Geist
- Mono: Geist Mono / IBM Plex Mono for tech tags
