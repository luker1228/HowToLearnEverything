# My Practice Sentences 📝

These are **my own original sentences** — insights I built myself using templates from my lessons. This file tracks my progress expressing thoughts in English.

## What really strikes me is how similar the way an agent works is to the way humans learn

**Template used:** *"What strikes me is how similar [A] is to [B] — [why they're alike]."*

### My polished sentence:
> "What really strikes me is how similar the way an agent works is to the way humans learn — both need to learn, practice, get feedback, and repeat."

### What it means:
An AI agent and a human learn the same way — through a loop:
**learn → practice → get feedback → repeat.**
The "training loop" is the same idea, whether it's code or a person.

### Grammar I learned from this sentence:
- **third-person `-s`:** it / he / she / singular noun + verb-**s**
  → "the agent **works**", "a human **learns**", "it **needs**"
  *(my most common mistake — watch for it!)*
- **similar TO** (not *similar than* or *similar with*): "how similar A is **to** B"
- **`feedback` is a noun** (uncountable), not a verb → use **get / give / receive feedback**
  - ❌ "I learn, practice, and feedback."
  - ✅ "I learn, practice, and **get feedback**."
- **"the way… the way…"** reads cleaner than "how… how…" in long sentences
- articles: "**an** agent" (not "agent")

### My draft → polished:
> ~~"What really strikes me is how simliar the way agent works is to the way the way human learn - both need to learn, practice and feedback, and repeat."~~
>
> ✅ "What really strikes me is how similar the way **an** agent works is to the way humans learn — both need to learn, practice, **get feedback**, and repeat."
