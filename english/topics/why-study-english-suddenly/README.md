## How this folder works

```text
                    ┌──────────────────┐
                    │     core.md      │  ← only source of facts / phrases
                    │  (one material)  │
                    └────────┬─────────┘
              ┌──────────────┴──────────────┐
              ▼                             ▼
     writing/essay.md              speaking/interview.md
     作文 · continuous text        口语 · interviewer 连问
```

| File | Role |
|------|------|
| **[core.md](./core.md)** | Shared spine, monologue, phrases, errors — **edit story here first** |
| **[writing/essay.md](./writing/essay.md)** | Essay form — paragraphs for **writing** |
| **[speaking/interview.md](./speaking/interview.md)** | Interview Q chain — short answers for **speaking** |
| **[homework/](./homework/)** | Dated assignments |

**Workflow:**

1. Change facts / lines only in `core.md`.  
2. Refresh essay model + interview **A** lines from core (same meaning, different shape).  
3. Practice writing **or** speaking; do not maintain two different life stories.

## Why two forms?

| | Writing (作文) | Speaking (对话/面试) |
|--|----------------|----------------------|
| Shape | Continuous paragraphs | 2–4 sentences per Q |
| Pressure | Connectors, flow, polish | Follow-ups, no freeze |
| Trap | List-like “answers” | Dumping the whole essay in Q1 |
| Win | One readable piece | Survive continuous digging |

Same material. Different muscle.
